## Học bằng cách xây dựng sản phẩm

Corelia Academy đồng hành cùng lập trình viên và sinh viên Việt Nam qua các chương trình thực hành về **phát triển ứng dụng, AI và blockchain**. Không chỉ đọc tài liệu: bạn viết code, kiểm thử và hoàn thiện sản phẩm của mình.

Đây là nơi chúng tôi chia sẻ tài liệu học, bài tập và mã nguồn để bạn bắt tay vào làm.

### Chọn điểm bắt đầu

| Bạn muốn… | Bắt đầu tại đây |
| :--- | :--- |
| **Học Solana theo lộ trình** | [**Solana Developer Bootcamp →**](https://github.com/corelia-academy/solana-bootcamp) — 18 module, từ nền tảng Rust đến project và capstone. |
| **Thực hành viết program** | [**Solana Program Lab →**](https://github.com/corelia-academy/solana-program-lab) — bài học Rust & Anchor, có starter và solution để đối chiếu. |
| **Hiểu blockchain qua tương tác** | [**Blockchain Interactive Demo →**](https://github.com/corelia-academy/blockchain-interactive-demo) — khám phá hash, block, giao dịch và chữ ký số bằng demo trực quan. |

### Từ bài học đến sản phẩm

**01 · Hiểu mô hình** &nbsp; → &nbsp; **02 · Viết code** &nbsp; → &nbsp; **03 · Kiểm thử** &nbsp; → &nbsp; **04 · Hoàn thiện project**

Khám phá thêm [**Corelia App**](https://github.com/corelia-academy/corelia-app), mã nguồn ứng dụng của Corelia Academy.

### Cùng xây dựng

Bạn gặp lỗi trong bài học, có cách giải thích dễ hiểu hơn hoặc muốn cải thiện một ví dụ? Mở **Issue** hoặc gửi **Pull Request** tại repository tương ứng. Với Solana Program Lab, hãy đọc [hướng dẫn đóng góp](https://github.com/corelia-academy/solana-program-lab/blob/main/CONTRIBUTING.md) trước khi bắt đầu.
