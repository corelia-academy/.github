## Corelia Academy

We help developers and students in Vietnam learn application development, AI, and blockchain through hands-on projects.

- [Solana Bootcamp](https://github.com/corelia-academy/solana-bootcamp) — a structured course with lessons, exercises, and projects.
- [Solana Program Lab](https://github.com/corelia-academy/solana-program-lab) — practical Rust and Anchor lessons.
- [Blockchain Demo](https://github.com/corelia-academy/blockchain-interactive-demo) — interactive examples of blockchain concepts.
- [Corelia App](https://github.com/corelia-academy/corelia-app) — the source code for our application.
